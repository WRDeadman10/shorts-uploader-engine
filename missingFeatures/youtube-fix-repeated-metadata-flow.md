# YouTube Fix Repeated Metadata Flow

The Electron UI does not expose the maintenance workflow from `youtubeFixRepeatedMetadata.py`.

Why it matters:

- repeated titles and descriptions are a real operational problem
- the script already exists and the Tkinter launcher already supports it

Expected outcome:

- dedicated maintenance screen or action
- support for mode, keep-first behavior, max updates, dry-run, and required YouTube auth files
