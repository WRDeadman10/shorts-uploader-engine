# Missing Features

This folder contains one short Markdown brief per missing Electron + React UI feature.

Purpose:

- help an AI or developer understand the gap quickly
- map the missing UI capability back to the existing Python scripts
- make implementation planning easier without rereading the whole repo

Scope:

- these docs compare the React + Electron app in `app/`
- against the currently available script capabilities in the repository root
- and, where useful, against the richer Tkinter launcher in `projectUiLauncher.py`

Each file is intentionally brief and implementation-oriented.
