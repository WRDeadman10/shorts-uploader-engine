# Advanced AI Metadata Settings

The Electron UI only has a simple "AI Metadata" toggle and misses the advanced metadata controls already supported by the script.

Notable missing options:

- OpenAI model
- channel name hint
- Instagram / YouTube username cross-link fields
- extra keywords
- language
- category ID
- notify subscribers
- AI uniqueness window
- AI metadata retry count

Why it matters:

- metadata quality is a major part of the upload pipeline
- these values influence output style and publishing behavior

Expected outcome:

- advanced metadata section in the upload flow
- persisted operator defaults
- support in command preview and process launch
